## Descripción del Proyecto
Aplicación móvil desarrollada en React Native con Expo que cumple con los requisitos del Módulo 5:
1. **Splash Screen e Ícono:** Personalizados.
2. **Pantalla 1:** Muestra información del estudiante (Nombre, Carnet, Sección).
3. **Pantalla 2:** Consume la API de FakeStore para mostrar productos.
4. **Arquitectura:** Uso de Custom Hooks para separar la lógica de la UI.
5. **Componentización:** Componentes reutilizables como `<Card />`, `<Loading />` y `<Navbar />`.
6. **Navegación:** Implementada con React Navigation.
